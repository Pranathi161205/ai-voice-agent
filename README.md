# VaaniAI Voice Agent – Real-Time Conversational AI Assistant
https://vaaniaivoiceagents.netlify.app/
## Overview

AI Voice Agent is a real-time conversational voice assistant designed to provide seamless speech-to-speech interaction using modern AI technologies. The application enables users to communicate naturally with the assistant through voice input and receive intelligent AI-generated voice responses in real time.

The system integrates Speech-to-Text (STT), Large Language Models (LLMs), and Text-to-Speech (TTS) technologies to create an interactive and human-like conversational experience. :contentReference[oaicite:0]{index=0}

**Clone the Repository**

**Backend Setup**
pip install -r requirements.txt
uvicorn serverlive:app --reload

Backend runs on:

http://127.0.0.1:8000

**Frontend Setup**
cd frontend
npm install
npm run dev

Frontend runs on:

http://localhost:5173
